Decodelabs "AI Order Status Prediction System" Project 2

Project Overview

This project is a Machine Learning based web application that predicts the status of an order using customer and order information. The model is trained using supervised learning and deployed using Flask.

Project Features

Predict Order Status using AI
Supervised Machine Learning Model
Simple Web Interface

Install the required libraries

Train the model

python train_model.py
Run the application

python app.py
Open the application in your browser

http://127.0.0.1:5000
